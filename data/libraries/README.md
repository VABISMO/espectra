# Spectral libraries

CSV in the `wavelength_nm,reflectance` format (µm, `%`, `;`/tab and
`wavelength/reflectance` headers are also detected). Recommended header:

```
# name: Hematite HS22
# category: mineral
# source: USGS splib05a
wavelength_nm,reflectance
400.0,0.0421
...
```

## Current contents

- `usgs/` — USGS Digital Spectral Library splib05a, 740 spectra
  (475 minerals, 110 vegetation, 104 soils/mixtures, 39 artificial,
  12 coatings). Public domain. Generated by `scripts/fetch_usgs.py`
  from <https://pubs.usgs.gov/of/2003/ofr-03-395/>.
- `pigments/` — 116 measurements of 24 mineral and synthetic pigments
  (ASD FieldSpec 4 Hi-Res NG, 350-2500 nm). Carrino et al. 2025,
  DOI 10.5281/zenodo.14906872. Generated by `scripts/fetch_pigments.py`.
- `revigo/` — 168 historical pigment mixtures (Eosin, Cochineal, Minium,
  vermilion…) measured over white and black grounds, 400-700 nm / 10 nm.
  Revigo project, CC0. Generated by `scripts/fetch_revigo.py`.

Not every file is usable: `match` only compares spectra that cover at
least 60 % of the working grid (400–700 nm), which leaves roughly 815 of
the 1,024 candidates.

## Adding your own spectra

Any two-column CSV will do. If you have a laboratory spectrometer, a
spectroscopy plugin or ECOSTRESS/CSIRO downloads, convert them to
`wavelength_nm,reflectance` and drop them here (in your own
subdirectory). The `match` command loads them recursively.

ECOSTRESS `.spectrum.txt` files are read as-is (parser included).

## Manual downloads that cannot be scripted

- **ECOSTRESS/ASTER** (JPL, 3400+ spectra, 0.4-25 µm): request at
  <https://speclib.jpl.nasa.gov/download> → unzip and convert, or leave
  the `.spectrum.txt` files in a subdirectory.
- **USGS Spectral Library v7** (ScienceBase, behind Cloudflare):
  <https://www.sciencebase.gov/catalog/item/586e8c88e4b0f5ce109fccae>
  → `ASCIIdata_splib07a.zip`. Format: one reflectance column, wavelengths
  in a separate file (`splib07a_Wavelengths_*.txt`) in microns; join both
  columns when converting.
